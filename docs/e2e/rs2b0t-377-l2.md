# Revision 377 L2 live cells

Run from the repository root against an operator-owned revision 377 engine. Do not start, stop, rebuild, or repack the engine.
`out/collision.lcnav.gz` must match `data/manifest.json`; the deploy refuses it otherwise.

```sh
ENGINE_DIR=... L2_LIVE_EVIDENCE_DIR=... bun e2e/l2-boneburier-377-live.ts --base http://localhost:81
```

Each cell runs three times by default (`L2_LIVE_RUNS`), each run on a fresh `frl2` account with no save on the engine.
The deploy is isolated (`deployIsolatedClient`, seeded `bot.html`) and is removed when the cell ends.
The receipt file in `L2_LIVE_EVIDENCE_DIR` lists, per run, every labelled setup cheat (`seeds`), the steps, every server readback, the checks, the product logs and any walker stall.

## Readbacks

A readback reads server-sent state only: `::getvar` replies, the player-update tile, `UPDATE_INV_*` for the pack and the bank, and `UPDATE_STAT` experience.
Every cell takes a `before` readback before the product acts and an `after` readback when it is done, then relogs cleanly and reads the login payload again (`after-relog`).
A run passes only when both readbacks exist and every check passes.

Setup cheats touch the account's own state only and never the transition under test. `mainlandAccount` moves each fresh account off Tutorial Island with `tutorial=1000` and a clean relog.
